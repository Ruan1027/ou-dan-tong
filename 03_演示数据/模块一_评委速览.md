# 模块一 · 模拟数据 · 评委速览

> 版本 v1.1 ｜ 确定性生成（无随机，重复运行字节级一致）｜ 共 22 组场景 / 46 条口语化多轮消息

## 一句话定位
为瓯单通智能体提供「可直接导入、有真实感、有陷阱」的温州中小企业业务群聊模拟数据，
覆盖**模块二（抽取/校验）**、**模块四（查询应答）**、**模块五（测试走查）** 的全部输入与断言基准。

## 数据规模
| 维度 | 数量 | 说明 |
|---|---|---|
| 总组数 | 22 组 | 远超 A1 要求的 ≥11 |
| 总消息 | 46 条 | 多轮口语对话 |
| 五类核心场景 | 各 3 组 | 新建/迭代更新/缺失/冲突/异常，≥ A1 要求的每类 2 组 |

## 场景清单与关键陷阱
- **新建订单 S1-G1~G3**：别称归一（「法兰」≈「304法兰盘DN80」）、口语交期（下周/周五/月底前）、跨行业（机械/电气/鞋服）。
- **多次迭代更新 S2-G1~G3**：数量/交期多轮变更、履历累积、复用 S1 主键**不新建**。
- **缺失信息 S3-G1~G3**：「那批」「一车」「老规矩」指向不明 → **缺失追问**。
- **矛盾冲突 S4-G1~G3**：数量 300vs280、交期 25/28/29、单价 18vs18.5 双口径 → **冲突标红、不自动覆盖**。
- **明显异常 S5-G1~G3**：负数量 -300、交期倒挂、数量多打零 5000 → **拦截不写入**。
- **动态演进 S6-E1/E2**：长链多轮、分两批交付、跨 客户/业务员/车间/老板娘 协商落定。
- **任务派发 S7-T1/T2**：要素齐全→ok；缺负责人/期限→追问（映射模块二 `classify_task` / BUG-05）。
- **取消/部分交付/价格报价 S8/S9**：走状态机到「已取消」、分批到货、报价态流转。

## 五类陷阱设计（评委可重点检视）
1. **别称归一**：客户口语「法兰」↔ 台账「304法兰盘DN80」。
2. **残缺指代**：「那批」「加一批」「一车」「老规矩」缺主体。
3. **口语时间**：「下周」「周五」「月底前」需近似换算为具体日期。
4. **多角色交叉**：客户 / 业务员 / 车间 / 仓库 / 老板娘 / 财务 六类角色同台。
5. **真实笔误**：负数量、交期倒挂、数量多打一个零（5000）。

## 模块映射
- **模块二**：抽取 → 变更识别（缺失/冲突/异常）的输入与断言基准，每组 `expected.validator_target` 直接对应 `ok|missing|conflict|abnormal`。
- **模块四**：查询应答的事实基础——动态演进组查询「那单到哪了」须返回**最新分批方案**而非旧版本。
- **模块五**：五类 + 动态演进逐组断言（明细见 `02_智能体代码/ou_dan_tong/模块五_测试报告.md`）。

## 如何运行 / 复用
```bash
cd 03_演示数据
python gen_sim_chats.py              # 生成 + 自检（A1~A4，任一不通过则非零退出）
python gen_sim_chats.py --check-only # 仅校验已有 chat_logs.json
python make_preview.py              # 生成 preview/模块一_数据预览.html（含类型筛选）
```
- **自定义场景注入**：`python gen_sim_chats.py --scenarios extra.json`
  （支持 `list[group]` 或 `{"groups":[...]}`，与内置语料确定性合并）。
- **红线**：页面与数据集全部为团队自建模拟内容，企业名已作化名处理，不涉及任何真实企业信息。
