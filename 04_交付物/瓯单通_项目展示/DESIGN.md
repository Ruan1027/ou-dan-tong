# 瓯单通 · 设计稿

## 画布与母版
1280×720；三区母版：
- **A 标题块** 0–120px：页面主标题 34px bold，左对齐，x=72；副标 16px 灰
- **B 内容区** 120–660px：正文 / 卡片 / 图表
- **C 页脚条** 660–720px：左「瓯单通 · 企业智能体赛道 · 队伍 XO」14px；右「NN / 10」14px，x 右对齐 72
- padding：上下 20、左右 72

## 色彩（4 hex）
| 角色 | hex | 用途 |
|---|---|---|
| 背景 主色 | `#0F172A` | 全篇深蓝墨背景、大色块 |
| 主色 蓝 | `#3B82F6` | 标题强调、图标、渐变起色 |
| 辅色 青 | `#06B6D4` | 渐变止色、数据高亮、连接线 |
| 文本 米白 | `#F7F4EC` | 正文、标题 |

- 渐变：`linear-gradient(135deg,#3B82F6 0%,#06B6D4 100%)` 用于封面主视觉条、关键卡片头、锚点数字底。
- 半透明：卡片 `rgba(247,244,236,0.06)`，描边 `rgba(247,244,236,0.14)`；强调块 `rgba(6,182,212,0.12)`。
- 面积分配：主色背景 ≤60%；辅/强调（蓝青）≤10%（只给锚点数字、关键指标）；中性米白为主。
