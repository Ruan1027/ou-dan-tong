# 瓯单通 · 运行与验证说明

> 赛道：AI＋企业智能体 ｜ 作品：瓯单通（碎片化沟通中的订单与任务协同） ｜ **队伍：XO**
> 适用对象：评审 / 演示人员 ｜ 阅读目标：5 分钟内跑起来并验证核心流程
> **开箱默认：真实模式**（包内已内置大模型接入配置 `ou_dan_tong/.env`）
**最快上手：解压后双击 `打开网页.html` 看指引，双击 `启动_Windows.bat` 起服务**

---

## 0. 开箱默认（真实模式）

交付包内已内置大模型接入配置 `ou_dan_tong/.env`，**开箱即进入真实模式**：

| 能力 | 是否调用大模型 | 表现 |
| --- | --- | --- |
| 群聊抽取（贴消息 → 结构化字段） | ✅ 调用 | 实时解析任意自由文本 |
| 查单 / 简报 / 台账 | ❌ 本地规则引擎 | **秒回**，不依赖网络 |

> ⚠️ **网络依赖与一键降级**：真实模式依赖外部大模型网关，抽取偶发 10~45 秒。
> 若现场网络不佳或抽取超时，只需把 `ou_dan_tong/.env` **删除或改名**并重启，
> 即回到**模拟模式**：秒回、稳定，查单 / 简报 / 台账完全可用
> （仅抽取步展示预置演示数据，界面会诚实标注「模拟模式」）。

## 1. 运行环境

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows / macOS / Linux 均可 |
| 运行时 | **Python 3.10+**（零第三方依赖，仅用标准库 `http.server` + 内置模块） |
| 硬件 | 任意能跑 Python 的机器 |
| 外部依赖 | **无**。大模型为**可选项**——默认「模拟模式」无需任何 API Key 即可完整演示 |
| 浏览器 | Chrome / Edge / Firefox 任一，用于打开本地 Web 界面 |

> 本项目为纯 Python 零依赖网页智能体，不依赖 Node、不依赖数据库、不依赖联网。

## 2. 启动步骤

### 2.1 一键启动（推荐，无需命令行）

| 系统 | 操作 | 效果 |
| --- | --- | --- |
| Windows | **双击 `启动_Windows.bat`** | 自动定位程序目录并起服务，窗口内提示访问地址 |
| macOS / Linux | 双击或执行 **`启动_Mac_Linux.sh`**（`bash 启动_Mac_Linux.sh`） | 同上 |
| 先看一眼 | **双击 `打开网页.html`** | 引导页：3 秒后自动跳进系统；服务未起时给出操作指引 |

脚本会自动检测 Python（≥3.10），缺失时给出下载地址；对含中文 / 空格的路径也做了兼容。

> ⚠️ **保持脚本弹出的黑窗口不要关闭**——关闭即停止服务。

### 2.2 命令行启动

```bash
# 进入作品目录
cd ou_dan_tong

# 启动（包内已内置 Key，直接进入「真实模式」）
python web_app.py
```

启动成功后终端会打印类似：

```
瓯单通 Web 服务已启动：http://127.0.0.1:8000  （真实模式（deepseek-ai/DeepSeek-V4.1-Flash，硅基流动 SiliconFlow））
```

打开浏览器访问 **http://127.0.0.1:8000** 即可。

> 换端口（端口被占用时）：`OU_PORT=9000 python web_app.py`

### 2.3 关于网页文件的位置（重要）

界面文件为 **`ou_dan_tong/static/index.html`**，它由本地服务提供，
**不能直接双击打开**——它是服务端驱动的应用，脱离服务会提示「网络异常，未能连接智能体」。
正确做法永远是：**先起服务，再访问 `http://127.0.0.1:8000`**。

## 3. 演示准备（30 秒）

1. 浏览器打开后，界面顶部若显示 **「模拟模式（未配置 API Key，演示用预置数据）」** 即为正确演示状态。
2. 点击界面上的 **「重置 / 重新播种」** 按钮（或调用 `POST /api/reset`），自动 seed **5 笔模拟在途订单**到台账。
3. 界面有两个 Tab：
   - **「微信沟通」**：模拟把群聊消息贴进来，看智能体抽取成结构化字段；
   - **「平台汇总」**：做查询、看台账、出每日简报。

> 演示数据全部为自造模拟数据，不含任何真实企业信息（符合比赛数据红线）。

## 4. 核心流程验证案例（输入 → 处理 → 输出）

以下案例在「模拟模式」下均**已实测通过**，查单/简报为**真实规则引擎**、秒级返回。

### 案例 A · 查询单条订单（真实逻辑）
- **输入**（平台汇总）：`李姐那批 DZ47 断路器到哪了`
- **处理**：本地规则引擎匹配客户「李姐（瓯越五金贸易）」+ 产品「DZ47-63 三相断路器」，读取台账实时状态。
- **输出**（0.0s）：结构化卡片——客户、产品、数量、有效交期、当前状态（沟通中/已确认等）、批次明细（如有）。

### 案例 B · 每日简报（真实逻辑）
- **输入**（平台汇总）：`出今日简报`
- **处理**：遍历台账，按有效交期计算在途 / 临期 / 逾期 / 今日待跟进。
- **输出**（0.0s）：四类统计 + 各单要点，可直接用作晨会播报。

### 案例 C · 群聊抽取（模拟模式演示交互形态）
- **输入**（微信沟通）：`王总：轴承6204 加到 200 个，交期下月5号`
- **处理**：模拟模式下返回**预置抽取卡片**（界面已诚实标注「模拟模式」），演示「群聊 → 结构化字段」的交互形态。
- **说明**：真实模式（配置 Key 后）会调用大模型实时解析任意自由文本；真实模式依赖外部大模型网关，演示建议用模拟模式以保证稳定。

## 5. 故障恢复

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| **抽取**很慢或超时（10~45 秒，偶发失败） | 处于「真实模式」，走了外部大模型网关（查单/简报不受影响，是本地秒回） | 想提速：删除或改名 `ou_dan_tong/.env` 并清掉环境变量里的 Key，重启即回「模拟模式」（秒回、稳定） |
| 页面空白 / 看不到最新内容 | 浏览器缓存了旧版 | `Ctrl+F5` 强刷（本服务已设 `Cache-Control: no-store`） |
| 端口被占用 | 8000 已被其他程序占用 | `OU_PORT=9000 python web_app.py` 换端口，访问对应地址 |
| 台账数据想恢复初始 | 演示中把数据改乱了 | 点「重置」按钮或 `POST /api/reset` 重新播种 |
