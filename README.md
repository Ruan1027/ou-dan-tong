## 二、怎么跑（智能体原型）

```bash
cd 02_智能体代码/ou_dan_tong
python web_app.py
# 浏览器打开 http://127.0.0.1:8000
```

- **未配 Key = 模拟模式**：预置数据演示完整流程（免费、零配置）。
- **配 Key = 真实模式**：在 `ou_dan_tong/.env` 填 `OPENAI_BASE_URL` / `OPENAI_API_KEY` / `OPENAI_MODEL`（任意 OpenAI 兼容端点，如硅基流动 `deepseek-ai/DeepSeek-V4.1-Flash`），重启即走真实大模型。
- 测试：`python test_pipeline.py`（另有 scenarios / defects / real_mode / e2e 共五套，见 `ou_dan_tong/README.md`）。
